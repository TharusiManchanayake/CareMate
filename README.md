# 🌿 CareMate

**A smart medicine reminder app designed for elderly people and their caregivers.**

CareMate helps an older adult take the right medicine at the right time, with loud alarm-style reminders, large readable text, and a one-tap emergency button. Caregivers manage the schedule behind a PIN so the patient can't accidentally change it.

---

## Features

### For the patient
- **Today's medicines** – only medicines due today are shown, with big **Taken / Snooze / Skip** buttons.
- **Reminders** – choose a normal *notification* or a loud *alarm* (max priority, full-screen, vibration) per medicine. Reminders survive phone reboots.
- **Notification actions** – mark a dose *Taken* or *Skip* straight from the notification, even when the app is closed.
- **SOS button** – shares the current GPS location (saved to Firestore) and opens the phone dialer to call the caregiver.
- **Health vitals** – log blood pressure, blood sugar, heart rate, oxygen and weight; the latest reading of each is shown.
- **Medication log** – full history of taken / missed / snoozed doses with filters.
- **Medicine stock** – stock bars with a "running low" warning.
- **Doctor visits** – keep notes from each visit and flag when a prescription was received.
- **Prescription scanner** – take a photo of a prescription, read it with on-device OCR (Google ML Kit), and turn it into a new medicine.
- **Ask CareMate** – a simple chat helper that answers questions about today's medicines, missed doses and doctor visits using the app's real data.

### For the caregiver (behind a 4-digit PIN)
- Add and remove medicines, with:
  - Daily or specific-weekday schedules
  - Optional end date
  - Custom reminder time and style
- **Settings screen**: patient name, caregiver phone number (used by SOS), caregiver PIN, default reminder style, and app-wide **text size** (Normal / Large / Extra large).

## Getting started

### Prerequisites
- Flutter SDK (Dart `^3.13.1`)
- Android Studio or VS Code with the Flutter extension
- A Firebase project (for Firestore sync and SOS logging)

### Setup

```bash
# 1. Install dependencies
flutter pub get

# 2. Connect your own Firebase project
dart pub global activate flutterfire_cli
flutterfire configure

# 3. Run on a connected Android device
flutter run
```

`flutterfire configure` regenerates `lib/firebase_options.dart` and `android/app/google-services.json` for your project.

### Android permissions used

Camera, fine location, notifications, exact alarms, boot completed, vibrate. On Android 12+ you may need to allow **Alarms & reminders** for the app so alarms fire on time. If exact alarms are blocked, the app falls back to inexact scheduling and logs it in the debug console.

## Data storage

- **On the device** (`shared_preferences`): medicines, history, vitals, doctor visits, settings.
- **Firestore**: medicines (`medicines` collection, one document per medicine) and SOS alerts (`sos_alerts`).

---

## Known limitations

- **No authentication or Firestore security rules yet.** Anyone with the Firebase config could read or write the data. Before real-world use, add Firebase Auth for caregivers and rules that require `request.auth != null`.
- **Caregiver PIN is a convenience lock, not real security.** It stops accidental edits, but is stored in plain text on the device.
- **Snooze only logs the action.** It does not yet reschedule a reminder 15 minutes later.
- **"Ask CareMate" is keyword matching**, not a language model. It only understands a few question types.
- **Recurring reminders are scheduled via UTC wrapping** to avoid a timezone setup failure seen on one device. This is fine in regions without daylight saving (e.g. Sri Lanka), but reminders could drift by an hour twice a year in DST regions.
- **Release builds are signed with debug keys** and R8 minification is disabled. Set up a proper signing config before publishing to the Play Store.
- iOS, web and desktop are not configured.
